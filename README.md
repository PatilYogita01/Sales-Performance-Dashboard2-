# 📊 Sales Performance Dashboard

## 📌 Project Overview
This project analyzes sales data using SQL, Python, Excel, and Power BI. It provides interactive dashboards and business insights to help understand sales performance across regions, categories, and products.

## 🎯 Objectives
- Analyze sales performance
- Track revenue and profit
- Identify top-selling products
- Compare regional sales
- Build an interactive Power BI dashboard

## 🛠️ Tools & Technologies
- Power BI
- SQL
- Python (Pandas, Matplotlib)
- Microsoft Excel
- Git & GitHub

## 📁 Dataset
The dataset contains 1,000 sales records with the following columns:
- Order_ID
- Order_Date
- Customer_Name
- Region
- Category
- Product
- Quantity
- Unit_Price
- Sales
- Profit

## 📊 Dashboard KPIs
- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Sales by Region
- Sales by Category
- Monthly Sales Trend
- Top 10 Products
